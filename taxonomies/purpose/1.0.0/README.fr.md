# Taxonomie de finalités Open AIRS 1.0.0

[Read in English](README.md)

Les étiquettes de finalité sont le vocabulaire utilisé par les extractions
pour dire **à quoi sert une composition**. Elles décrivent une activité en
termes neutres et ne portent jamais de conclusion juridique : ce sont les
packs de règles qui traduisent étiquettes et faits en catégories légales, et
les circuits de l'organisation qui décident de la suite.

La taxonomie est versionnée comme un pack. Une extraction épingle l'identifiant
et la version utilisés, pour qu'une étiquette garde son sens dans le temps.
Ajouter une étiquette est une version mineure ; changer ou retirer le sens
d'une étiquette existante est une version majeure, expliquée au changelog.

Pour bien choisir les étiquettes :

- ne retenir que les finalités **actives**, jamais les simples mentions ou
  interdictions présentes dans les instructions ;
- préférer l'étiquette la plus précise ; associer `recruitment` et
  `candidate_selection` quand les candidatures sont à la fois traitées et
  évaluées ;
- si aucune étiquette ne convient, garder une formulation libre précise et
  proposer une nouvelle étiquette par évolution de la taxonomie ; détourner
  une étiquette existante appauvrit le vocabulaire pour tout le monde.
