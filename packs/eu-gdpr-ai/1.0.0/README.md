# EU GDPR AI core pack 1.0.0

This pack screens a governed AI use for selected GDPR questions. It does not
replace a record of processing activities, DPIA or legal analysis.

The Article 22 rule is intentionally separate from the AI Act high-risk route.
A use may match one, both or neither. Human review is assessed from runtime and
process evidence, not inferred from reassuring prose in an application prompt.

Source reviewed: official EUR-Lex text, 29 August 2026.
