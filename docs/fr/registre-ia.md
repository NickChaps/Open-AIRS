# Ce que contient le registre IA

L’inventaire de gouvernance est plus large que la seule liste juridique des
systèmes d’IA. C’est volontaire : il doit expliquer pourquoi un périmètre et
une finalité ont été retenus.

Pour chaque usage concret, une vue de registre utile présente :

- le nom, le responsable, la finalité métier et l’état du cycle de vie ;
- le système ou l’application configurée qui le réalise ;
- la plateforme, le modèle, les skills, les connecteurs et les fournisseurs ;
- les personnes concernées et les décisions ou actions importantes ;
- les données personnelles, sensibles ou protégées ;
- les contrôles du runtime : droits, validation humaine, journalisation et suivi ;
- la qualification AI Act, ses raisons et ses ancrages exacts ;
- les constats RGPD, cybersécurité et référentiels volontaires sur des axes séparés ;
- les preuves manquantes, obligations, responsables et échéances dans le produit hôte ;
- la version de l’évaluation, le snapshot source et l’historique des changements.

Un export juridique peut ne retenir que les éléments qui correspondent à la
définition choisie. L’inventaire conserve les composants explicatifs sans
présenter chaque modèle, skill ou connecteur comme un système d’IA autonome.
